// How to Build the Firmware

1
Fork & download the repo
Go to the GitHub repo and click Fork. Then download the ZIP or clone it:
git clone https://github.com/YOUR_USERNAME/esp32-cyd-sysmon
2
GitHub Actions auto-build (recommended)
Just push to main. The included .github/workflows/build.yml compiles the firmware automatically and publishes it as a GitHub Release. Download esp32-cyd-sysmon.bin from the Releases page.
3
Local build (optional)
Install PlatformIO, then:
cd firmware && pio run
The .bin appears at firmware/.pio/build/esp32dev/firmware.bin
4
Load into this flasher
Drag the .bin onto the firmware drop zone (left sidebar). It's saved to your browser — you'll never need to load it again on this machine.
5
Flash & run
Connect your CYD, click Flash Firmware, then run the agent:
pip install psutil pyserial
python sysmon-cross.py
